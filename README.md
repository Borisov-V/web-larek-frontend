# Проектная работа "Веб-ларек"

Стек: HTML, SCSS, TS, Webpack

Структура проекта:

- src/ — исходные файлы проекта
- src/components/ — папка с JS компонентами
- src/components/base/ — папка с базовым кодом

Важные файлы:

- src/pages/index.html — HTML-файл главной страницы
- src/types/index.ts — файл с типами
- src/index.ts — точка входа приложения
- src/scss/styles.scss — корневой файл стилей
- src/utils/constants.ts — файл с константами
- src/utils/utils.ts — файл с утилитами

Карточка товара

```Typescript
interface IProductItem {
  id: string;
  description: string;
  image: string;
  title: string;
  category: string;
  price: TPrice;
}
```

Интерфейс для модели данных карточек товаров

```Typescript

  items: IProductItem[];
  preview: string | null;

```

Корзина

```Typescript

  items: IProductItem[];

```

Данные заказа

```Typescript
interface IOrder {
  payment: 'online' | 'offline';
  email: string;
  phone: string;
  address: string;
  total: TPrice;
  items: TOrderProductItem[];
}
```

Данные стоимости

```Typescript

```

Данные карточки товара на главной странице

```Typescript

```

Данные карточки товара в корзине

```Typescript
type TBasketProductItem = Pick<IProductItem, 'title' | 'price'>;
```

Данные товара в заказе

```Typescript
type TOrderProductItem = Pick<IProductItem, 'id'>;
```

Данные адреса доставки и способа оплаты в заказе

```Typescript

```

Контактные данные в заказе

```Typescript
type TOrderContacts = Pick<IOrder, 'phone' | 'email'>;
```

Данные заказа на экране успешной покупки

```Typescript

```

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP:

- слой представления, отвечает за отображение данных на странице
- слой данных, отвечает за хранение и изменение данных
- презентер, отвечает за связь представления и данных

### Базовый код

#### Класс Api

Содержит в себе базовую логику отправки запросов. В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.
Методы:

- `get` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер
- `post` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется 'POST' запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.

#### Класс EventEmitter

Реализует паттерн «Наблюдатель» и позволяет подписываться на события и уведомлять подписчиков
о наступлении события.
Класс имеет методы `on` , `off` , `emit` — для подписки на событие, отписки от события и уведомления
подписчиков о наступлении события соответственно.
Дополнительно реализованы методы onAll и offAll — для подписки на все события и сброса всех
подписчиков.
Интересным дополнением является метод trigger , генерирующий заданное событие с заданными
аргументами. Это позволяет передавать его в качестве обработчика события в другие классы. Эти
классы будут генерировать события, не будучи при этом напрямую зависимыми от
класса EventEmitter .

#### Класс Component

Класс реализует общие методы для всех компонентов представления.

Методы класса:

- `setDisable(element: HTMLElement, state: boolean): void` - устанавливает и снимает с элемента аттрибут Disable
- `setText(element: HTMLElement, value: string): void` - устанавливает textContent для элемента
- `setImage(element: HTMLElement, src: string, alt: string)` - устанавливает изображение с альтернативным текстом
- `render(data: Partial<T>): HTMLElement` - принимает объект со свойствами для изменения в полях экземпляра класса. Возвращает заполненный элемент разметки

### Компоненты модели данных

#### Класс ProductItemsData

Класс отвечает за хранение и логику работы с карточками товаров.\
Конструктор класса принимает инстанс брокера событий.

Свойства класса:

- `items: IProductItem[]` - массив объектов карточек товаров
- `preview: string | null` - id карточки выбранной для просмотра в модальном окне
- `events: IEvents` - экземпляр класса `EventEmitter` для инициации событий при изменении данных

Методы класса:

- `setItems(items: IProductItem[]): void` - добавляет массив карточек товаров в свойство `items` и вызывает событие изменения массива
- `getItems(): IProductItem[]` - возвращает массив карточек товаров из свойства `items`
- `getItem(itemId: string): IProductItem` - возвращает одну карточку по ее id

#### Класс BasketData

Класс отвечает за хранение и логику работы с карточками товаров, которые были добавлены в корзину.\
Конструктор класса принимает инстанс брокера событий.

Свойства класса:

- `items: IProductItem[]` - массив объектов карточек товаров в корзине
- `events: IEvents` - экземпляр класса `EventEmitter` для инициации событий при изменении данных

Методы класса:

- `setItem(item: IProductItem): void` - добавляет карточку в массив `items` и вызывает событие изменения массива
- `getItems(): IProductItem[]` - возвращает массив карточек `items`
- `getItemsCount(): number` - возвращает количество карточек в корзине
- `deleteItem(itemId: string): void` - удаляет карточку из массива `items` по ее id и вызывает событие изменения массива.
- `deleteAll(): void` - очищает массив `items` и вызывает событие изменения массива
- `getTotalPrice(): TPrice` - возвращает общую стоимость товаров из массива `items`

#### Класс OrderData

Класс отвечает за хранение и логику работы с данными заказа, которые вводит пользователь.\
Конструктор класса принимает инстанс брокера событий.

Свойства класса:

- `_payment: 'online' | 'offline'` - способ оплаты заказа
- `_email: string` - электронная почта пользователя
- `_phone: string` - телефон пользователя
- `_address: string` - адрес доставки
- `_total: TPrice` - общая стоимость товаров в заказе
- `_items: TOrderProductItem[]` - массив id товаров, которые пользователь добавил в заказ
- `events: IEvents` - экземпляр класса `EventEmitter` для инициации событий при изменении данных

Методы класса:

- `getOrder(): IOrder` - возвращает объект с данными заказа готовый для отправки на сервер
- Сеттеры и геттеры для сохранения и получения данных из полей класса

### Компоненты представления

Компоненты представления отвечают за отображение внутри контейнера (DOM - элемент) передаваемых в них данных.

#### Класс Modal

Реализует модальное окно. Устанавливает слушатели на клик по оверлею и кнопке-крестик для закрытия модального окна.
Конструктор принимает контейнер модального окна для заполнения контентом, а также экземпляр класса `EventEmitter`.

Свойства класса:

- `_content: HTMLElement` - элемент помещаемый внутрь модального окна
- `_closeButton: HTMLButtonElement` - элемент кнопки закрытия модального окна
- `events: IEvents` - экземпляр класса `EventEmitter` для инициации событий

Методы класса:

- `open(): void` - открывает модальное окно
- `close(): void` - закрывает модальное окно, очищает `_content`
- `render(data): void` - расширяет родительский метод `render()`, принимает объект со свойством `content`, изменяет `_content` и вызывает метод `open()`
- Сеттеры для установления значений полей класса

#### Класс Card

Отвечает за отображение карточки товара. В конструктор передается DOM элемент темплейта, что позволяет формировать карточку в разных вариантах верстки. Так же в конструктор передается объект с коллбеком.\
Класс устанавливает слушатель на кнопку и вызывает коллбек из конструктора, при отсутствии кнопки слушатель устанавливается на карточку.

Свойства класса:

- `_title: HTMLElement`
- `_image: HTMLImageElement`
- `_description: HTMLElement`
- `_category: HTMLElement`
- `_price: HTMLElement`
- `_button: HTMLButtonElement`

Методы класса:

- Геттеры и сеттеры для установления и получения значений полей класса

#### Класс BasketView

Класс отвечает за отображение корзины со списком товаров, которые были в нее добавлены. В конструктор передается DOM элемент темплейта, коллбек для установки слушателя на кнопку.

Свойства класса:

- `_list: HTMLElement`
- `_total: HTMLElement`
- `items: HTMLElement[]`
- `_button: HTMLButtonElement`

Методы класса:

- Сеттеры для установления значений полей класса

#### Класс OrderForm

Класс отвечает за отображение формы заказа. Конструктор принимает DOM элемент темплейта, коллбек для установки слушателя на кнопку.

Свойства класса:

- `_payment: HTMLInputElement`
- `_email: HTMLInputElement`
- `_phone: HTMLInputElement`
- `_address: HTMLInputElement`
- `_button: HTMLButtonElement`
- `_errors: HTMLElement`

Методы класса:

- Сеттеры для установления значений полей класса

#### Класс Success

Класс отвечает за отображение уведомления о успешно оформленном заказе. Конструктор принимает DOM элемент темплейта, коллбек для установки слушателя на кнопку.

Свойства класса:

- `_image: HTMLImageElement`
- `_title: HTMLElement`
- `_button: HTMLButtonElement`
- `_total: HTMLElement`

#### Класс CardContainer

Класс отвечает за отображение галереи с карточками товаров на главной странице.

Свойства класса:

- `_container: HTMLElement`

Методы класса:

- Сеттер для добавления массива элементов карточек в контейнер.

### Слой коммуникации

#### Класс AppApi

Принимает в конструктор экземпляр класса Api и предоставляет методы реализующие взаимодействие с бэкендом сервиса.

Слой презентера не будет выделен в отдельный класс, код описывающий взаимодействие данных и представления находится в файле `index.ts`.\
Взаимодействие осуществляется за счет событий, генерируемых брокером событий `EventEmitter` и обработчиков событий описанных в `index.ts`.

В `index.ts` сначала создаются экземпляры всех необходимых классов, а затем настраивается обработка событий.

##### Список всех событий, которые могут генерироваться в системе:

События данных, генерируются моделью данных

- `items:changed` - изменение массива карточек товаров
- `basket:changed` - изменение массива товаров в корзине
- `preview:changed` - изменена карточка для просмотра
- `order:changed` - изменены данные заказа

События представления, генерируются интерфейсом

- `card:open` - открытие карточки товара
- `card:select` - выбрана карточка для добавления в корзину
- `card:unselect` - выбрана карточка для удаления из корзины
- `basket:open` - открытие корзины
- `basket:submit` - нажата кнопка оформить в корзине
- `form:input` - ввод данных в форме
- `form:submit` - нажата кнопка submit в форме
- `modal:open` - открытие модального окна
- `modal:closed` - закрытие модального окна
